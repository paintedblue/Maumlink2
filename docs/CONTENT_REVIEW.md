# 원본 PDF 콘텐츠 반영 기록

검토일: 2026-10-03. 사용자의 최신 지시: “just apply real contents (exactly) from each domain pdf”. 앞서 허용한 편집 판단보다 이 지시를 우선한다. 개발자가 새로 쓴 18개 초안의 편집·확정 방식은 폐기하고 원문 복원 또는 삭제로 처리했다.

## 원문과 반영 범위

| 영역 | 원본 PDF | 앱 시나리오 |
|---|---|---|
| 관계 관리 | 느린학습자_사회정서교육앱_콘텐츠설계서_관계 관리-박수빈.pdf | relation-pencil-prank |
| 관계 인식 | 느린학습자_사회정서교육앱_콘텐츠설계서_관계 인식-양수정.pdf | social-playground |
| 마음건강관리 | 느린학습자_사회정서교육앱_콘텐츠설계서_마음건강관리-김시은.pdf | mind-lunch-line |
| 자기 인식 | 느린학습자_사회정서교육앱_콘텐츠설계서_자기 인식-홍은비.pdf | self-presentation-teasing |

원본 PDF는 상위 작업 폴더에 보존한다. [`pdf-transcriptions.json`](../content-source/pdf-transcriptions.json)에 파일명, SHA-256, 각 문구의 실제 PDF 페이지 번호(1부터), 한국어 전사, 감정 순서 및 원문 누락을 기록했다. 본문의 하단 인쇄 번호는 실제 페이지보다 1 크다.

- 콘텐츠명, 목표, 상황 제목·이야기·핵심 문장, 감정 질문·선택지, STEP 3, 행동 질문·선택지·피드백, 마무리를 원문으로 반영했다.
- PDF 줄바꿈 및 문장부호 앞의 조판 공백만 정리했다. 어휘·어미·문장부호·원문 오탈자를 임의로 고치지 않았다. 관계 관리의 세 문장은 문장 단위로 나누어 표시한다.
- 자기 인식 이야기는 원문의 한 문장으로 복원했다. 새로 만든 두 도입 문장을 제거했다. 자기 인식 C 피드백의 누락 문장을 복원하고 D의 추가 문장을 삭제했다.
- PDF에 없는 `더 알려줘요` 본문·버튼과 관계 관리 이유 선택별 추가 답변을 제거했다. 사회/마음건강 PDF의 “선택한 이유를 인정한 뒤…”는 개발자에게 주는 피드백 원칙이므로 아동 대상 설명문으로 창작·변환하지 않았다.
- 도움말은 해당 PDF의 핵심 문장을 그대로 재사용한다. 자기 인식 PDF에는 글로 된 삽화 설명이 없어 원문 상황 제목을 대체 텍스트로 재사용한다.
- 감정 선택지 순서를 원문에 맞췄다. 자기 인식의 학생 작성란에 요청된 부끄러워요·무서워요를 포함했다. 잘 모르겠어요는 마음건강관리 마지막 요약 페이지(실제 p.10)에만 있으므로 해당 영역에만 유지했다. 그 요약과 상세 STEP 본문이 다를 때 실제 p.3–7의 상세 본문을 기준으로 한다.
- 기본 UI 문구, 현재 삽화, 진행·도움말 기능은 유지한다. 삽화는 PDF 원본의 복제본이 아닌 기존 생성 이미지다.
- 한국어가 배포 언어다. 변경된 원문과 의미가 어긋날 수 있는 기존 영문 번역은 제거했다. 해당 항목은 개발용 `?lang=en`에서도 한국어로 대체 표시된다. 영문은 PDF 원문이 아니다.

## 원문에 없는 설명: 새로 만들지 않음

| 영역 | 감정 | 원문 상태 | 앱 동작 |
|---|---|---|---|
| 관계 인식 | 서운해요 | p.4 선택지 있음, p.5 이유 없음 | 선택 감정과 원문 질문 표시, 다음 단계 이동 가능 |
| 자기 인식 | 부끄러워요 | p.4 추가 요청, p.5 신체반응 없음 | 선택 감정과 원문 질문·원칙 표시, 만들어 낸 반응·강조 없이 이동 가능 |
| 자기 인식 | 무서워요 | p.4 추가 요청, p.5 신체반응 없음 | 위와 동일 |

`sourceOmissions`로 위 세 누락을 명시했다. 다른 설명이 실수로 빠지면 기존 유효성 검사가 실패한다. 초안 0개는 원문에 모든 내용이 완비되었다는 뜻이 아니다.

## 그대로 보존한 원문 오탈자 예

| 영역 | 원문 위치 | 보존한 표현 |
|---|---|---|
| 관계 관리 | p.3 삽화 설명 / p.5 B / p.7 C | 강조하기 않기 / 연칠 / 바과하는 |
| 관계 인식 | p.6 A | 왜 나만 빼도 놀아! |
| 마음건강관리 | p.3 상황 | 이번에 첫번째가 아니예요. / 새채기 |
| 자기 인식 | p.5 속상해요 / p.7 C | 소개가 숙여진다 / 좋은 방법이예요. |

따옴표 모양·누락도 원문대로 유지했다. 수정하려면 원본 문구 수정 지시와 함께 전사 기록도 갱신한다.

## 검증과 남은 확인

- `pnpm validate:final-content`: 전사 기록과 배포 한국어를 전수 비교하며 추가·누락·변경 문구 및 감정 순서 변경을 검출한다. PDF 자체를 OCR로 재판정하는 검사는 아니다.
- 단위/화면 상호작용 테스트: 네 전체 학습 경로 및 위 세 원문 누락 경로가 다음 단계로 이어지는지 확인한다.
- 사용자가 배포 사이트에서 **Mac Chrome 음성 확인 및 자동 읽기가 모두 동작한다**고 확인했다. 이번 로컬 콘텐츠 변경 배포 이후의 기기 검증과는 구분한다.
- 사용자가 나머지 실제 기기 검증을 직접 진행하기로 했다. 이 기록에서 iPhone/iPad/Android 가로·세로/큰 글자 확인을 완료로 표시하지 않는다.
- 현재 실행 환경에서 브라우저 연결과 로컬 서버 실행이 제한된다. 새 브라우저/접근성/오프라인 결과는 미확인이다. CI 실행 및 스크린샷 검토도 별도 확인이 필요하다.
